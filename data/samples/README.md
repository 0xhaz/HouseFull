# Sample files

`meta-results-sample.csv`: invented Meta Ads results for the demo's check-in step. Upload it on a
brief's **Results** tab ("Upload Meta CSV"). Ad sets named `hf-s1…` map to the brief's audiences;
rows for audiences the brief doesn't have are listed as unmatched and ignored. The numbers clear
the re-plan threshold (≥ 50 clicks per audience or ≥ 5 sales), so **Re-plan from results** unlocks.
